🛡️ Stack Architecture Overview

Configured in **Queue Mode** using Redis as a job broker and PostgreSQL for credentials. This stack offloads all manual and automated executions to dynamically scaled worker nodes (`n8n-worker`) paired 1:1 with isolated Javascript/Python task runner sidecars (`n8n-worker-runner`).

Trigger Nodes Webhook, Google Drive, Cron, Telegram

⚡ Production Storage Optimization

We upgraded the binary data storage mode from database buffer mode to **filesystem mode** (`N8N_DEFAULT_BINARY_DATA_MODE=filesystem`). Files are streamed directly to disk, resolving memory spikes and connection drop errors (`ECONNRESET`) during large downloads.
